# Planet albedo textures

The nine JPEG maps in this folder (`mercury_albedo.jpg` through
`neptune_albedo.jpg`, plus `moon_albedo.jpg`) are 2048x1024 equirectangular
albedo maps.

* **Source:** [Solar System Scope textures](https://www.solarsystemscope.com/textures/)
* **Licence:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)
* **Basis:** Solar System Scope's maps are based on NASA imagery.

They are fetched by `tools/fetch_planet_textures.py` and committed so the game
ships without a download. Keep the attribution with the files when they are
copied or republished.
